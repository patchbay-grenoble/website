# Single-page website Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

Goal: turn the site into one page (`/`) with anchored sections, native `<dialog>` modals and a menu of anchor links, while keeping `/projets/<slug>/` as shareable pages.

Architecture: `index.astro` renders every section and every modal at build time. Modals are native `<dialog>` elements opened by `<button command="show-modal">` (Invoker Commands, no JavaScript). A shared `FicheProjet.astro` renders project content in the modal and on `/projets/<slug>/`. A ~10-line inline script syncs `#fiche-<slug>` with the open project modal. Old page URLs become meta-refresh pages generated by one dynamic route.

Tech stack: Astro 7.4.13 (static output), Bun 1.4.5 (`bun test`), html-validate 11 (`recommended` preset), lychee 0.24.2 (link check in CI), GitHub Actions.

Spec: `docs/superpowers/specs/2026-11-26-single-page-design.md`

Conventions for whoever executes this plan:

- Bun is not installed on the dev machine: run it as `npx -y bun@1.4.5 <args>`
- The agent never runs `git commit` or `git push`: each task ends with a checkpoint where David commits
- Code comments are in French, like the rest of the repo
- No trailing spaces
